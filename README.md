## Install

On macOS/Linux:

```sh
git clone https://github.com/Shchoholiev/codex-chaos-monkey.git
cd codex-chaos-monkey
./install.sh
```

Or extract the release ZIP and run `./install.sh`. On Windows, copy `root-monkey`
into `%USERPROFILE%\.codex\pets\`.

In Codex, open **Settings → Pets → Refresh**, choose **Chaos Monkey**, then enter `/pet`.

The installer uses `~/.codex/pets/` or `$CODEX_HOME/pets/`. To update, move the
existing `root-monkey` folder aside first.
